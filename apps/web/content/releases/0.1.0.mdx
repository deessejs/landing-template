# 0.1.0 — Initial Release

First release of landing-template.

## What's in 0.1.0

### Added

- **Landing page** — `apps/web`, public marketing surface with blog and changelog
- **Admin interface** — `apps/app`, closed-beta product surface with auth gate
- **Authentication** — better-auth with email/password, session management, and admin-only provisioning
- **Database** — Drizzle ORM with PostgreSQL, ready for your schema
- **API** — Hono + oRPC for type-safe backend procedures
- **UI Components** — shadcn/ui with Tailwind CSS v4
- **Blog** — content-collections with MDX, authors, tags, and RSS
- **Changelog** — Keep-a-Changelog format with semantic versioning
